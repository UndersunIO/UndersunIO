## 🚀 Currently building — Supralearning

**Supralearning** is my experimental ecosystem for exploring how software can make learning more interactive.

### 🧠 FlashLearning

A learning engine combining:

`AI-generated courses` · `Flashcards` · `Spaced repetition` · `Gamification` · `Progression`

Designed around short, interactive learning sessions rather than passive content consumption.

---

### 🤖 SupraLab AI

An interactive laboratory for learning **Artificial Intelligence by experimentation**.

Explore concepts such as:

`Rules` → `Q-Learning` → `Perceptrons` → `Neural Networks` → `Deep Reinforcement Learning`

The goal is to **see algorithms behave**, not just read about them.

---

### ⚡ SupraLab Electronics

A visual and interactive environment for understanding electronics through:

`3D components` · `Circuits` · `Experiments` · `Microcontrollers` · `PCB concepts`

Learning electronics by manipulating systems rather than memorizing diagrams.

---

### 💻 DevLab101

Interactive learning experiences for developers.

Focused on practical understanding through:

`Visual explanations` · `Real incidents` · `Interactive exercises` · `Developer tooling`

---

### 🧬 TrackEvolution

A personal operating system for tracking and understanding:

`Goals` · `Projects` · `Habits` · `People` · `Life metrics` · `Progress`

An experiment around building a **personal cockpit instead of another productivity app**.

## 🧩 Product Philosophy

I care less about adding features and more about answering:

**What should the user understand, feel or be able to do after using this?**

I like products that:

* reduce cognitive load
* make progress visible
* give immediate feedback
* transform abstract concepts into interactions
* reward exploration
* remain simple despite complex systems underneath
